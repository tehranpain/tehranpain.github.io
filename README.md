# 央企招聘导航

收录指定名单中的 98 家央企官方招聘入口，并提供企业搜索、行业筛选、收藏和 BOSS 直聘岗位搜索。

## GitHub Pages 发布

1. 新建一个公开 GitHub 仓库，例如 `yangqi-jobs`。
2. 将本文件所在目录中的所有文件上传到仓库根目录，不要只上传 ZIP 文件。
3. 打开仓库 `Settings > Pages`。
4. 在 `Build and deployment` 中选择 `Deploy from a branch`。
5. Branch 选择 `main`，目录选择 `/ (root)`，然后点击 `Save`。
6. 等待约 1 至 5 分钟，GitHub 会显示公开访问地址。

网站入口文件为 `index.html`，不需要安装依赖或执行构建命令。
